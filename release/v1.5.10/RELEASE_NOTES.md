## ViralCut 1.5.10

**Windows снова открывается, а субтитры больше не вылезают за кадр.**

### Windows: приложение не открывалось

- **Причина.** Оболочка на Windows запускается через `pythonw.exe` без консоли:
  любая ошибка до открытия окна завершала процесс молча, и пользователь видел
  «нажал — ничего не произошло». Плюс каждый запрос к базе оставлял открытое
  соединение SQLite — на Windows это блокировало файл базы (из-за этого падал
  CI и не собирался `.exe`).
- **Что сделано.** Соединения закрываются; самопроверка при старте не может
  уронить запуск; в `app.log` пишутся метки `[boot]` (видно, где остановилось);
  занятый экземпляр показывает диалог; `ViralCut.bat` при неудаче сам открывает
  консоль с текстом ошибки. Опрос GPU перенесён на момент после открытия окна.

### Субтитры: выходили за края кадра и выглядели «размытыми»

- **Причина.** Ширина строки считалась только под наш шрифт. Если libass
  подставлял системный (он шире на 15–20%), строки уезжали за кадр; длинное
  слово перенести нельзя, и вся реплика оставалась одной длинной строкой.
- **Что сделано.** Перенос строк минимизирует самую длинную строку; расчёт идёт
  с запасом; реплика и хук автоматически уменьшают кегль, если строка всё равно
  не влезает; шрифты для libass читаются напрямую из папки приложения (без
  копий в профиле). В `app.log` появилась строка
  `[render] шрифты libass: … (N файлов) — OK` — по ней видно, нашёлся ли шрифт.

Замер: было — строка занимала все 1080 px и обрезалась; стало — 797–955 px,
края кадра не задеваются ни нашим шрифтом, ни подставленным системным.

### Установка

- **Windows 10/11 x64:** `ViralCut-1.5.10-windows-x64.zip` — распакуйте и
  запустите `ViralCut.exe`. Без установки —
  `ViralCut-1.5.10-windows-x64-portable.zip` + `ViralCut.bat`.
- **macOS 12+ (Apple Silicon):** `ViralCut-1.5.10.dmg` — перетащить в
  «Программы», первый запуск ПКМ → «Открыть».

Если приложение не открылось — запустите `ViralCut-console.bat` (Windows) или
пришлите `app.log`: `%APPDATA%\ViralCut\app.log` / `~/Library/Application Support/ViralCut/app.log`.
