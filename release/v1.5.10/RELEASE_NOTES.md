## ViralCut 1.5.10

**Исправление Windows-сборки: приложение снова открывается.**

- **Не открывалось окно.** Настольная оболочка на Windows запускается через
  `pythonw.exe` без консоли. Если что-то ломалось до открытия окна, процесс
  завершался молча — пользователь видел «ничего не произошло».
  Теперь любая ошибка старта видна: `ViralCut.bat` при неудаче открывает консоль
  с текстом ошибки, занятый экземпляр показывает диалог, а в `app.log` пишутся
  метки этапов `[boot]` — по ним видно, где остановился запуск.
- **Утечка соединений SQLite.** Каждый запрос к базе оставлял открытое
  соединение: на Windows это блокировало файл БД (и валило тесты в CI, из-за
  чего не собирался `.exe`). Исправлено, соединения закрываются.
- **GPU на Windows читается после открытия окна**, а не на старте — сбой опроса
  счётчиков больше не может помешать запуску.

Установка: распакуйте `ViralCut-1.5.10-windows-x64-portable.zip` и запустите
`ViralCut.bat`. Если окно не появится — консоль покажет ошибку, а лог лежит в
`%APPDATA%\ViralCut\app.log`.
