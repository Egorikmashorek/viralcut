## ViralCut 1.5.13

**Процессор под контролем и выбор видеокарты.**

- **Лимит процессора 25–100%**: приложение больше не занимает машину целиком.
  На Windows потолок держит сама система, на macOS/Linux — диспетчер пауз.
- **Встроенная или дискретная видеокарта** — переключатель в настройках;
  на Windows предпочтение записывается в систему, на Intel Mac сборка считает
  на дискретной AMD.
- Сборки: macOS Apple Silicon, macOS Intel (x86_64), Windows x64.
